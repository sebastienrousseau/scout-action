# Support

Where to take a question, in the order most likely to get you an answer.

| You want | Read |

## Questions and discussion

[GitHub Discussions](https://github.com/sebastienrousseau/scout-action/discussions)
for anything about running scout in a pipeline. A question about a
verdict — why scout judged a server the way it did — belongs in
[scout's discussions](https://github.com/sebastienrousseau/scout/discussions).

## Bugs and feature requests

[GitHub Issues](https://github.com/sebastienrousseau/scout-action/issues),
using the templates. A good report includes the workflow step, the
action version, the step log with the token redacted, and the
`report.txt` from the report directory.

## Security

**Do not open a public issue for a vulnerability.** Follow the private
reporting process in [SECURITY.md](SECURITY.md).

## Response expectations

scout-action is maintained by one person alongside other work. Issues are
read within a week; security reports are prioritised per the SLA in
SECURITY.md. There is no commercial support offering.
